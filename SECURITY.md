# Política de seguridad

## Versiones con soporte

| Versión | Soporte |
|---|---|
| 2.1.x | Sí |
| 2.0.x | Solo fallos críticos |
| 1.x (Google Sheets / Apps Script) | No |

## Cómo reportar una vulnerabilidad

**No abras un *issue* público.** Usa la opción privada de GitHub: *Security → Report a vulnerability* en este repositorio. Incluye:

1. Una descripción del problema y su impacto.
2. Los pasos para reproducirlo (versión de WordPress, PHP y del plugin).
3. Si la tienes, una propuesta de corrección.

Responderemos lo antes posible y publicaremos la corrección junto con el reconocimiento a quien la reportó, si así lo desea.

## Buenas prácticas para quien instala el sistema

- No subas `wp-config.php`, volcados `.sql`, archivos `.env` ni copias de seguridad al repositorio.
- Usa HTTPS, contraseñas robustas y mantén WordPress, PHP y el plugin actualizados.
- Desactiva el modo demostración antes de la campaña real.
